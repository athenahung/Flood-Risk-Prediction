/floodrisk/: Root directory containing all files of this project
/floodrisk/rainfall_data.csv: Dataset with 6 columns
/floodrisk/preprocessing.txt: Preprocesses rainfall_data.csv using data cleaning, PCA, and normalization
/floodrisk/lstm.py: Trains model using LSTM and produces visualizations and classification report
/floodrisk/run_model.py: Runs a tuning analysis on LSTM to determine optimal number of time steps
/floodrisk/svm.py: Trains model using SVM and produces visualizations and classification report
/floodrisk/random_forest.py: Trains model using random forest and produces visualizations and classification report
